
# 📈 Option Pricing Algorithm | 期权定价算法实训

> **人大 2025 秋季学期 - 期权定价算法实训课程项目** \> 基于沪深300股指期货高频数据（500ms）对沪深300股指期权（IO）进行实时定价。

## 📖 项目背景

在瞬息万变的金融市场中，理解和应用复杂的金融工具对于洞察市场动态至关重要。本项目旨在基于实盘行情数据，运用经典金融模型（如 Black-Scholes）与现代机器学习方法（如 LightGBM），完成 **沪深300股指期权 (IO2507)** 的定价任务。

核心目标是利用高频期货行情驱动期权定价，最小化理论定价与市场中间价之间的平均绝对误差 (MAE)。

## 📂 项目结构与方法演进

本项目包含多种定价策略的尝试，从基础的 Demo 到复杂的混合模型，代码按文件夹分类如下：

| 文件夹 | 方法名称 | 描述 |
| :--- | :--- | :--- |
| **0. demo** | **基础示例** | 官方提供的基础 API 跑通示例，用于验证环境配置与数据读取流程。 |
| **1. BSM** | **BSM 经典模型** | 基于 Black-Scholes-Merton 公式的传统定价方法，计算隐含波动率进行定价。 |
| **2. ML** | **纯机器学习 (LGBM)** | 摒弃金融公式，直接使用 LightGBM 模型根据市场特征预测期权价格。 |
| **3. Hybrid** | **混合模型 (BSM+ML)** | 结合金融特征（Greeks）与机器学习，将 BSM 输出作为特征输入到 LightGBM 中。 |
| **4. Delta 锚定** | **Delta 锚定波动率** | 基于 Delta 建立波动率曲面 (Volatility Surface) 的方法，通过锚定 Delta 来推导价格。 |
| **5. Delta 锚定+LGBM 残差** | **残差修正模型** | **(核心策略)** 先使用 Delta 锚定模型计算基准价格，再利用 LightGBM 预测并修正残差 (Residual)，以捕捉非线性偏差。 |
| **6. Delta 锚定+Spline** | **样条插值优化** | 在 Delta 锚定的基础上，使用样条插值 (Spline) 技术平滑波动率曲面，提高定价精度。 |
| **参考文献** | **References** | 包含项目研究过程中参考的学术论文与技术文档。 |

## 🚀 快速开始

### 1\. 配置数据

在项目根目录或子模块目录下创建 `config.json`，指向本地行情数据路径：

```json
{
  "date": "20250623",
  "data_path": "../data/20250623"
}
```

### 2\. 运行代码

以 `5. Delta 锚定+LGBM 残差` 为例：

```bash
cd "5. Delta 锚定+LGBM 残差"
python main.py
```

运行成功后将生成：

  * `submission.csv`: 预测结果文件。
  * `iter_test_timing.json`: 运行耗时统计。

### 3\. 本地评测

使用提供的脚本计算 MAE：

```bash
python calculate_result.py
```

*输出示例*: `1.254969, 2.0380` (第一个值为 MAE，第二个值为运行时间)

## 🏆 考核指标

核心评估指标为 **平均绝对误差 (MAE)**：

$$MAE = \frac{1}{n} \sum_{i=1}^{n} |theoprice - midprice|$$

  * `theoprice`: 算法计算的理论价格
  * `midprice`: 市场买一价与卖一价的平均值
  * `n`: 所有合约的总 Tick 数

*注：MAE 越小，排名越靠前；同时考核代码运行效率（单次运行需 ≤10分钟）。*
